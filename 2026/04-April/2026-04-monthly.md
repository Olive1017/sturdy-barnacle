## 🧠 技术与认知收获

**写代码层面**

- PySide6 比 customtkinter 顺手太多，桌面小工具默认选型确定
- 信号槽：让代码像仆从一样，只听该听的声音，不用认识发声的人
- Playwright codegen + auth.json 复用登录态——这个套路下次直接抄
- log_signal vs print 的区别（开发期/上线期的不同需求）
- 实时写 Excel 防断电——做长跑型 RPA 的标配

**Git 层面**

- 学了 orphan branch
- 终于搞清 `git push -u origin master` 里 -u 是 --set-upstream 的简写，绑完后续直接 push 就行

**AI/智能体层面**

- agent loop 反复看了好几遍才真懂——"看一遍一带而过远远不够"这条比知识本身还重要
- MCP：不要教模型做所有事，教协议，让模型自己通过协议去拿信息和做事
- 收藏了"严格遵循 [SKILL.md](http://SKILL.md) 义理体系"这种人格化 prompt 玩法，感觉能玩出花样
- 想让小no 用"寓言讲研究生概念"的 prompt 讲一次 agent loop
