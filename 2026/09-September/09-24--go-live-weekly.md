## 🧠 学到 / 想明白的

- **Postman vs Python 的定位**：Postman 核心价值是“看”和“试”（改一个参数马上重发、看 Headers/Body/Response，不用先写代码）；Python 的核心价值是“自动化”和“集成”（批量调用、塞进程序、定时执行、接 FastAPI/数据库/任务队列）。两者不是替代关系，而是调试与集成分工。
- **AI 协作心态（来自园长即刻）**：
    - 心态额倒过来——失败成本低，不会编程的全交给 AI 反而做得快，要多试。
    - 工作时间一律开着 AI，像 pair programming，问“这个功能在第几行？这个重构麻烦吗？”，慢慢从手动档过渡到自动档。
    - 细节的事交给 AI（它比人细心），自己把时间重心放在 plan 和 test 上。
- 继续用 deerpark skill 探索 GitHub Copilot Skill 的底层原理：Skill = 提示词 + 任务模板 + 工具调用策略 + 约束规则，让模型知道“怎么用外部资料源回答”，而不是靠记忆。
