## 🧠 学到 / 想明白的

- API 不只是“向别人的服务器要数据”，还需要考虑数据封装、用户视角和接口边界，不能简单把底层返回结果原样暴露出去。
- CI/CD 的核心是让代码从“写完”到“上线”的全过程尽可能自动化。现在已经会使用 Git 管理项目，但还没有真正把 GitHub 当成完整的软件交付流水线。
- 开始绘制自己的 IT 知识地图，区分已经学习、正在学习和还未学习的内容，并初步确定未来几个月的学习方向。
- 继续思考如何与 AI 协同学习和办公，并阅读、讨论了《On Working with Wizards》。
