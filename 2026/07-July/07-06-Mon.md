    - origin 不是命令关键字，而是一个**别名（昵称）**，指向远程仓库地址，它是你 git clone 的时候 Git **自动**帮你起的默认名字，用来代替那一长串仓库 URL。所以git push -u origin subdir等价于git push -u [https://github.com/Olive1017/redesigned-octo-lamp.git](https://github.com/Olive1017/redesigned-octo-lamp.git) subdir
    - **field（字段）= 存储的事实**。它是"被赋值"进来的，是数据的**源头/家**。**property（属性）= 现算的推导**。它不存，每次访问时**临时从别的数据算出来**。一句话：**field 是"我拥有的"，property 是"我算出来的"。**
