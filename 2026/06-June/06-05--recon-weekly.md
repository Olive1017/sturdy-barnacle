这周和上周完全是两种节奏。上周是埋头改算法(rewrite),这周更像是从代码里抬起头——先去现场看真东西,再把视野拉远,看看自己和行业要往哪走。一周下来主线不是"做",而是"看清楚再做"。

周一还在收尾上一段:AI 比赛的采购项目继续推,顺手领了个新的 API key。这天偏杂,没什么大事。

周二学了个让我有点兴奋的东西——Notion 能直接连 GitHub 的 MCP,意味着可以让 Notion AI 直接进代码库里改东西。工具链又往"动手做"的方向打通了一格:以前是"我想 → 描述 → 复制粘贴 → 跑",现在中间那几步正在被一点点抹掉。

周三是这周的转折点:去现场考察万益特。这趟最大的收获不是技术,而是发现——**纸上的装柜计划,和搬运工现场的实际做法,根本不是一回事。** 算法算得再漂亮,落不到现场就是空的。这件事一直在我脑子里转:真正的约束不在 Excel 里,在柜门口那几个人手上。

周四顺着这个发现,把万益特的装柜计划重新梳理了一遍——这次不是调算法参数,而是先退回去想"这个工具到底该放在流程的哪个环节、给谁用"。下午去了物流展会,线下看了看行业现在在玩什么。

周五几乎一整天在跟 AI 深聊自己的职业规划和行业动向。聊出来一个挺关键的认知:我现在干的这种"懂物流 + 指挥 AI 做东西"的活,在外面其实有正经的岗位名字(Forward Deployed Engineer 这一类),而且是眼下增长最快的方向之一。
